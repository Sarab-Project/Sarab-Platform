================================================================================
                     SECTION 1: AUTHORIZATION ARCHITECTURE
================================================================================

The Sarab Platform uses JWT (JSON Web Token) based authentication with a refresh
token mechanism for secure, stateless authentication.

AUTHORIZATION FLOW:
-------------------

1. USER SIGNUP/LOGIN
   └─ Receive: Access Token (JWT) + Refresh Token
   └─ Access Token Expiry: 60 minutes
   └─ Refresh Token Expiry: 30 days

2. STORE TOKENS LOCALLY
   └─ Access Token: Store in localStorage or memory (recommended: memory for security)
   └─ Refresh Token: Store in localStorage with proper security (HttpOnly if possible)

3. USE ACCESS TOKEN FOR REQUESTS
   └─ Add to Authorization Header: "Bearer {accessToken}"
   └─ All protected endpoints require this header

4. TOKEN REFRESH
   └─ When Access Token expires (60 min), use Refresh Token to get new Access Token
   └─ Call: POST /api/auth/refresh with RefreshToken in body
   └─ Continue using same Access Token until refresh is needed

5. LOGOUT
   └─ Call: POST /api/auth/logout
   └─ Send Refresh Token in body to invalidate session
   └─ Clear both tokens from local storage
   └─ Redirect user to login page

TOKEN CLAIMS (contained in Access Token):
-----------------------------------------
- sub: User ID
- email: User Email
- name: User First Name
- nameid: User ID (duplicate for compatibility)
- email (claim type): User Email
- role: User Role (Admin, Contributor, Researcher)
- iat: Issued At (timestamp)
- exp: Expiration (timestamp)
- iss: Issuer ("SarabPlatform")
- aud: Audience ("SarabPlatformUsers")

JWT STRUCTURE:
--------------
{
  "Header": {
    "alg": "HS256",
    "typ": "JWT"
  },
  "Payload": {
    "sub": "1",
    "email": "user@example.com",
    "name": "John",
    "role": "Researcher",
    "exp": 1234567890,
    "iss": "SarabPlatform",
    "aud": "SarabPlatformUsers"
  },
  "Signature": "HMACSHA256(base64UrlEncode(header) + '.' + base64UrlEncode(payload), secret)"
}

AUTHORIZATION MIDDLEWARE CONFIGURATION:
----------------------------------------
- Scheme: Bearer
- Key: ChangeThisToASecretKeyWithAtLeast32Chars!
- Issuer: SarabPlatform
- Audience: SarabPlatformUsers
- Token Validation: Checks signature, expiry, issuer, and audience


================================================================================
                     SECTION 2: HTTP REQUEST HEADERS
================================================================================

REQUIRED HEADERS FOR ALL REQUESTS:
----------------------------------

Content-Type:
  "application/json" (for JSON requests)
  "multipart/form-data" (for file uploads)

Authorization (For Protected Endpoints):
  "Bearer {accessToken}"
  Example: "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

OPTIONAL HEADERS:
-----------------

User-Agent: 
  Automatically sent by browser, used by server for session tracking

Accept:
  "application/json"

CORS POLICY:
-----------
The backend allows:
- All Origins (*)
- All Methods (GET, POST, PUT, DELETE, OPTIONS, etc.)
- All Headers

1. SIGNUP (User Registration)
   ────────────────────────────
   Endpoint: POST /api/auth/signup
   Access: Public (No Authorization Required)
   Description: Register a new user account

   Request Headers:
   - Content-Type: application/json

   Request Body:
   {
     "firstName": "John",
     "lastName": "Doe",
     "email": "john.doe@example.com",
     "password": "SecurePassword123"
   }

   Request Validation:
   - firstName: Required, minimum 3 characters
   - lastName: Optional
   - email: Required, valid email format
   - password: Required, minimum 8 characters

   Success Response (200 OK):
   {
     "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxIiwiZXhwIjoxNjk5NDcyNDAwLCJpc3MiOiJTYXJhYlBsYXRmb3JtIn0.SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c",
     "refreshToken": "rO0JayJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9eyJzdWIiOiIxIn0",
     "expiresAt": "2026-05-07T14:00:00Z",
     "user": {
       "id": 1,
       "firstName": "John",
       "lastName": "Doe",
       "email": "john.doe@example.com",
       "profileImagePath": null
     }
   }

   Error Response (409 Conflict):
   {
     "message": "Email is already registered."
   }

   Error Response (400 Bad Request):
   {
     "errors": {
       "password": ["The Password field is required."],
       "email": ["The Email field is not a valid e-mail address."]
     }
   }

   Frontend Implementation:
   - Store token and refreshToken securely
   - Store user info in state/context
   - Redirect to dashboard/home page
   - Set up automatic token refresh mechanism

7. REVIEW USER DOCUMENT (Admin Only)
   ─────────────────────────────────
   Endpoint: PUT /api/users/documents/{documentId}/review
   Access: Protected (Requires Admin role in JWT token)
   Description: Review and approve/reject a user document
                Only admins can perform this action

   URL Parameters:
   - documentId: Document ID (integer)

   Request Headers:
   - Authorization: Bearer {accessToken}
   - Content-Type: application/json

   Request Body:
   {
     "status": 0,
     "rejectionReason": "Document quality is insufficient"
   }

   Status Values:
   - 0: Pending
   - 1: Approved
   - 2: Rejected
   - (Check DocumentStatus enum for exact values)

   RejectionReason: Optional, required if status is Rejected

   Example Request:
   {
     "status": 1,
     "rejectionReason": null
   }

   Success Response (200 OK):
   {
     "message": "Document reviewed successfully"
   }

   Error Response (401 Unauthorized):
   {
     "message": "Invalid user token" or "Unauthorized"
   }

   Error Response (403 Forbidden):
   (If user is not admin - implicit in token validation)

   Error Response (404 Not Found):
   {
     "message": "Document not found"
   }

   Error Response (400 Bad Request):
   {
     "message": "Cannot review a deleted document"
   }

   Frontend Implementation:
   - Admin dashboard component
   - Document review interface
   - Approve/Reject buttons
   - Reason text field
   - Show review status updates

                     SECTION 4: ERROR HANDLING
================================================================================

COMMON HTTP STATUS CODES:
─────────────────────────

200 OK
  - Request succeeded
  - Contains response data

201 Created
  - Resource successfully created
  - Contains created resource data

204 No Content
  - Request succeeded
  - No response body (e.g., DELETE operations)

400 Bad Request
  - Invalid request parameters or body
  - Validation errors
  - Missing required fields

401 Unauthorized
  - Missing or invalid authentication token
  - Token expired
  - Insufficient permissions

403 Forbidden
  - Authenticated but not authorized for this resource
  - Role-based restrictions

404 Not Found
  - Resource does not exist
  - Invalid URL/endpoint

409 Conflict
  - Resource already exists (e.g., duplicate email)
  - State conflict

500 Internal Server Error
  - Server error
  - Unexpected exception

503 Service Unavailable
  - Server temporarily unavailable
  - Maintenance


ERROR RESPONSE FORMAT:
─────────────────────

Validation Error (400):
{
  "errors": {
    "fieldName": ["Error message 1", "Error message 2"],
    "anotherField": ["Error message"]
  }
}

Business Logic Error:
{
  "message": "User-friendly error message"
}

Server Error (500):
{
  "message": "Internal server error",
  "error": "Detailed error information (dev only)"
}


FRONTEND ERROR HANDLING:
───────────────────────

1. Check HTTP status code
2. Parse error response
3. Display user-friendly error message
4. Log error for debugging
5. Take action based on error type:
   - 401: Redirect to login, refresh token, or logout
   - 403: Show permission denied message
   - 404: Show not found message
   - 400: Highlight validation errors on form
   - 500: Show generic error, log to monitoring

Example Error Handler:
```
async function handleApiError(response) {
  if (response.status === 401) {
    // Try refresh token
    await refreshAccessToken();
    // Retry original request
  } else if (response.status === 403) {
    showMessage("You don't have permission for this action");
  } else if (response.status === 404) {
    showMessage("Resource not found");
  } else if (response.status === 400) {
    const error = await response.json();
    if (error.errors) {
      showValidationErrors(error.errors);
    } else {
      showMessage(error.message);
    }
  } else if (response.status >= 500) {
    showMessage("Server error. Please try again later");
    logError(response);
  }
}
```


================================================================================
                     SECTION 5: TOKEN MANAGEMENT GUIDE
================================================================================

STORING TOKENS SECURELY:
────────────────────────

Access Token (JWT):
  - Store in memory (most secure, lost on page refresh)
  - OR localStorage (persistent, but XSS vulnerable)
  - OR sessionStorage (persistent until tab close)
  - Use memory + sessionStorage for best balance
  - NEVER store in cookies without HttpOnly flag

Refresh Token:
  - Store in localStorage with encryption
  - OR in HttpOnly cookie (server sends only)
  - Set up automatic cleanup on logout

Example Storage Implementation:
```javascript
// Store tokens after login
function storeTokens(response) {
  // Access token in memory
  accessToken = response.token;
  
  // Refresh token in localStorage
  localStorage.setItem('refreshToken', response.refreshToken);
  
  // Store token expiry
  tokenExpiryTime = new Date(response.expiresAt).getTime();
}

// Get access token
function getAccessToken() {
  return accessToken;
}

// Check if token expired
function isTokenExpired() {
  return Date.now() >= tokenExpiryTime;
}

// Clear tokens
function clearTokens() {
  accessToken = null;
  localStorage.removeItem('refreshToken');
  tokenExpiryTime = null;
}
```


TOKEN REFRESH STRATEGY:
──────────────────────

Method 1: Proactive Refresh
- Refresh 5-10 minutes before expiry
- Set timer when token received
- Auto-refresh without user action

```javascript
function setupTokenRefresh(expiresIn) {
  // Refresh 5 minutes before expiry
  const refreshTime = (expiresIn - 5) * 60 * 1000;
  
  setTimeout(async () => {
    await refreshAccessToken();
  }, refreshTime);
}

async function refreshAccessToken() {
  try {
    const refreshToken = localStorage.getItem('refreshToken');
    const response = await fetch('/api/auth/refresh', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ refreshToken })
    });
    
    if (response.ok) {
      const data = await response.json();
      storeTokens(data);
      setupTokenRefresh(data.expiresAt);
    } else {
      // Refresh failed, redirect to login
      logout();
    }
  } catch (error) {
    console.error('Token refresh failed:', error);
    logout();
  }
}
```

Method 2: Reactive Refresh
- Refresh only when 401 response
- Prevents unnecessary requests
- Requires request retry logic

```javascript
async function makeAuthenticatedRequest(url, options) {
  try {
    let response = await fetch(url, {
      ...options,
      headers: {
        ...options.headers,
        'Authorization': `Bearer ${getAccessToken()}`
      }
    });
    
    if (response.status === 401) {
      // Try refresh token
      const refreshed = await refreshAccessToken();
      if (refreshed) {
        // Retry original request
        response = await fetch(url, {
          ...options,
          headers: {
            ...options.headers,
            'Authorization': `Bearer ${getAccessToken()}`
          }
        });
      } else {
        logout();
      }
    }
    
    return response;
  } catch (error) {
    console.error('Request failed:', error);
    throw error;
  }
}
```


REQUEST INTERCEPTOR PATTERN:
────────────────────────────

```javascript
// For Axios
axios.interceptors.request.use(
  config => {
    const token = getAccessToken();
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  error => Promise.reject(error)
);

// Response interceptor for token refresh
axios.interceptors.response.use(
  response => response,
  async error => {
    if (error.response?.status === 401) {
      const refreshed = await refreshAccessToken();
      if (refreshed) {
        return axios.request(error.config);
      }
    }
    return Promise.reject(error);
  }
);
```

```javascript
async function logout() {

    if (refreshToken) {
```

```typescript
const API_BASE_URL = 'http://localhost:5000';

interface AuthResponse {
  token: string;
  refreshToken: string;
  expiresAt: string;
  user: UserPublic;
}

interface UserPublic {
  id: number;
  firstName: string;
  lastName: string;
  email: string;
  profileImagePath?: string;
}

let accessToken: string | null = null;
let refreshToken: string | null = null;

// SIGNUP
async function signup(firstName: string, lastName: string, email: string, password: string) {
  const response = await fetch(`${API_BASE_URL}/api/auth/signup`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ firstName, lastName, email, password })
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Signup failed');
  }

  const data: AuthResponse = await response.json();
  storeTokens(data);
  return data.user;
}

// LOGIN
async function login(email: string, password: string) {
  const response = await fetch(`${API_BASE_URL}/api/auth/login`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password })
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Login failed');
  }

  const data: AuthResponse = await response.json();
  storeTokens(data);
  return data.user;
}

// REFRESH TOKEN
async function refreshAccessToken() {
  if (!refreshToken) throw new Error('No refresh token');

  const response = await fetch(`${API_BASE_URL}/api/auth/refresh`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ refreshToken })
  });

  if (!response.ok) {
    clearTokens();
    window.location.href = '/login';
    throw new Error('Token refresh failed');
  }

  const data: AuthResponse = await response.json();
  storeTokens(data);
  return accessToken;
}

// LOGOUT
async function logout() {
  try {
    if (refreshToken && accessToken) {
      await fetch(`${API_BASE_URL}/api/auth/logout`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${accessToken}`
        },
        body: JSON.stringify({ refreshToken })
      });
    }
  } finally {
    clearTokens();
    window.location.href = '/login';
  }
}

// STORE TOKENS
function storeTokens(data: AuthResponse) {
  accessToken = data.token;
  refreshToken = data.refreshToken;
  localStorage.setItem('refreshToken', data.refreshToken);
}

// CLEAR TOKENS
function clearTokens() {
  accessToken = null;
  refreshToken = null;
  localStorage.removeItem('refreshToken');
}

// FETCH WITH AUTH
async function fetchWithAuth(url: string, options: RequestInit = {}) {
  const headers = {
    ...options.headers,
    'Authorization': `Bearer ${accessToken}`
  };

  let response = await fetch(url, { ...options, headers });

  if (response.status === 401) {
    try {
      await refreshAccessToken();
      response = await fetch(url, { ...options, headers: { ...headers, 'Authorization': `Bearer ${accessToken}` } });
    } catch {
      window.location.href = '/login';
      throw new Error('Authentication failed');
    }
  }

  return response;
}

// Example: Get user profile
async function getUserProfile(userId: number) {
  const response = await fetchWithAuth(`${API_BASE_URL}/api/users/${userId}`);
  return response.json();
}
```

REACT EXAMPLE WITH CONTEXT:

```tsx
import React, { createContext, useState, useContext } from 'react';

interface AuthContextType {
  user: UserPublic | null;
  accessToken: string | null;
  isAuthenticated: boolean;
  signup: (data: SignupData) => Promise<void>;
  login: (email: string, password: string) => Promise<void>;
  logout: () => Promise<void>;
}

const AuthContext = createContext<AuthContextType | undefined>(undefined);

export function AuthProvider({ children }: { children: React.ReactNode }) {
  const [user, setUser] = useState<UserPublic | null>(null);
  const [accessToken, setAccessToken] = useState<string | null>(null);

  const login = async (email: string, password: string) => {
    const response = await fetch('/api/auth/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ email, password })
    });

    if (!response.ok) throw new Error('Login failed');

    const data = await response.json();
    setAccessToken(data.token);
    setUser(data.user);
    localStorage.setItem('refreshToken', data.refreshToken);
  };

  const logout = async () => {
    try {
      await fetch('/api/auth/logout', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${accessToken}`
        },
        body: JSON.stringify({ refreshToken: localStorage.getItem('refreshToken') })
      });
    } finally {
      setAccessToken(null);
      setUser(null);
      localStorage.removeItem('refreshToken');
    }
  };

  return (
    <AuthContext.Provider value={{ user, accessToken, isAuthenticated: !!accessToken, login, logout, signup }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  const context = useContext(AuthContext);
  if (!context) throw new Error('useAuth must be used within AuthProvider');
  return context;
}
```
